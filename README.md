# Neon Bar Online 3D

## Chạy trên máy tính
1. Cài Node.js bản LTS: https://nodejs.org/
2. Giải nén thư mục.
3. Mở Terminal/CMD tại thư mục này.
4. Chạy:
   ```bash
   npm install
   npm start
   ```
5. Mở http://localhost:3000

## Cho bạn bè vào cùng phòng
- Máy chủ phải được đưa lên hosting/VPS có hỗ trợ Node.js và WebSocket (ví dụ Render, Railway hoặc VPS).
- Sau khi deploy, gửi đường dẫn website cho bạn bè.
- Không thể nhiều người ở các mạng khác nhau cùng vào chỉ bằng `localhost`.

## Điều khiển
- WASD hoặc phím mũi tên: di chuyển.
- Nút Nhảy: bật/tắt nhảy.
- Chat và nút emoji: tương tác với mọi người.

Đây là bản demo nền tảng. Chưa có tài khoản, lưu dữ liệu, voice chat, hệ thống quà tặng thanh toán hay công cụ quản trị nâng cao.
